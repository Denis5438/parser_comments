# 🤖 Giveaway Contest Bot (Telegram-бот для проведения честных розыгрышей)

Автоматизированный Telegram-бот на **Node.js / TypeScript** для сбора комментариев, исключения накрутчиков (тех, кто оставляет по несколько комментариев) и честного присвоения порядковых номеров (1, 2, 3... $N$) с формированием отчета в **Excel**.

Поддерживает **4 платформы:**
* 🔴 **YouTube** (обычные видео, Shorts, трансляции)
* 🔵 **ВКонтакте** (посты на стене и видеозаписи)
* 🟠 **Дзен** (статьи, посты и видеоролики)
* 🟣 **Instagram** (посты и Reels без браузера и без токенов от заказчика)

---

## ⚡ Особенности и преимущества

1. **Легковесный режим (Zero-Browser):**
   * Никаких Chromium, Puppeteer или Playwright.
   * Потребляет всего **60–90 МБ оперативной памяти**.
   * Стабильно работает даже на самых слабых VPS (512 МБ – 1 ГБ RAM).

2. **Zero-Setup для заказчика (в Instagram и Дзен):**
   * Заказчику не нужно создавать приложения в Meta Developers или давать свои пароли.
   * Сбор в Instagram происходит по чистому HTTPS через встроенный шлюз.

3. **Гибкие правила отсева накрутки:**
   * 🟢 **Режим «Первый засчитан» (по умолчанию):** самый ранний комментарий пользователя засчитывается, все его последующие комментарии отсеиваются в список дублей.
   * 🚫 **Режим «Дисквалификация»:** если участник оставил $\ge 2$ комментариев, он полностью удаляется из розыгрыша за накрутку.
   * 💬 **Учет вложенных ответов:** возможность включить или отключить сбор ответов в ветках комментариев.

4. **Профессиональный Excel-отчет (`.xlsx`):**
   * **Вкладка 1 («Участники розыгрыша»):** присвоенные номера 1...N, никнеймы, кликабельные ссылки на профили, тексты комментариев, дата/время.
   * **Вкладка 2 («Исключенные повторы»):** детальный лог отсеянных комментариев и спамеров для разрешения любых спорных ситуаций.

5. **Встроенный рандомайзер:**
   * Определение победителя прямо в Telegram в 1 клик с выводом ссылки на профиль и текста победного комментария.

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Настройка конфигурации (.env)
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```
Заполните параметры в `.env`:
* `TELEGRAM_BOT_TOKEN`: токен вашего бота от [@BotFather](https://t.me/BotFather).
* `YOUTUBE_API_KEY`: бесплатный ключ YouTube Data API v3 из Google Cloud Console (для YouTube).
* `VK_SERVICE_TOKEN`: сервисный ключ приложения ВКонтакте из [vk.com/dev](https://vk.com/dev) (для VK).
* `INSTAGRAM_SESSION_ID`: *(опционально)* sessionid cookie, если требуется авторизованный сбор закрытых постов в Instagram.

### 3. Запуск бота
```bash
# Режим разработки с автоперезагрузкой:
npm run dev

# Обычный запуск:
npm start
```

### 4. Постоянная работа на сервере (через PM2)
Для непрерывной работы бота на слабом сервере рекомендуется использовать `pm2`:
```bash
npm install -g pm2
pm2 start "npm start" --name "giveaway-bot"
pm2 save
pm2 startup
```
